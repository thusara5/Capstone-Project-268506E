
# Uncertainty-Aware Inventory Forecasting

## Project Overview

An MSc capstone project investigating whether uncertainty-aware machine learning forecasts can improve retail inventory replenishment decisions.

## Research Objectives

- Forecast retail demand using machine learning.
- Estimate demand uncertainty using prediction intervals.
- Compare traditional, point-forecast, and uncertainty-aware inventory strategies.
- Evaluate forecasting accuracy and inventory performance.

## Dataset

**Dataset Name:** Retail Store Inventory and Demand Forecasting

**Source:** [Kaggle - Retail Store Inventory and Demand Forecasting](https://www.kaggle.com/datasets/atomicd/retail-store-inventory-and-demand-forecasting)
